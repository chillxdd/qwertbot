Available response variables
$(user) or $user
The viewer who triggered the command. Example: Hello $(user)! → Hello SomeViewer!
$(touser) or $touser
The first argument after the trigger, with a leading @ removed. Falls back to the triggering viewer. Example: !bonk @Qwert with Bonked $(touser)! → Bonked Qwert!
$(query) or $query
Everything after the trigger. Example: !say hello there with You said: $(query) → You said: hello there
$(count) or $count
This command group's persistent counter after the successful trigger increments it. Example: Hydration #$(count) → Hydration #42
$(random MIN MAX)
A random whole integer from MIN through MAX, inclusive. Example: You rolled $(random 1 100)! → You rolled 73!. Negative bounds are allowed too.
$(randomuser)
Picks a random user currently connected to Qwert's Twitch chat using Twitch's Get Chatters API. Example: $(randomuser) has been selected! → SomeViewer has been selected!
