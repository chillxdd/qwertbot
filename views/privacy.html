SqwertArmyBot Privacy Policy

Last updated: September 22, 2026

This Privacy Policy explains how SqwertArmyBot, a livestream chat automation bot used for GeneralQwert's Twitch and YouTube streams, accesses, uses, stores, and shares information. The YouTube integration is used to connect the SqwertArmyBot YouTube channel to active livestream chats so the bot can respond to configured commands and post configured timer messages.

SqwertArmyBot does not sell Google or YouTube user data, use it for advertising, or use YouTube live chat data to train AI models. The YouTube integration is intentionally separate from QwertBot's Gemini recap, Tagged Questions, Viewer Profiles, and memory systems.

1. Google and YouTube data we access

When the SqwertArmyBot operator connects the bot through Google OAuth, the application may access the following information through the YouTube Data API:

  • The authorized bot channel's YouTube channel ID and display name.
  • OAuth access and refresh tokens, granted scopes, and token expiration information.
  • Public information about active GeneralQwert YouTube broadcasts, including video IDs, titles, and active live chat IDs.
  • Live chat information needed to operate commands: message text, message ID, publish time, the author's channel ID and display name, and whether the author is the chat owner, a moderator, or a sponsor/member.

2. How we use Google and YouTube data

SqwertArmyBot uses this information only to provide its livestream chat features, including:

  • Verifying that OAuth is connected to the intended SqwertArmyBot YouTube channel.
  • Finding active GeneralQwert YouTube livestreams and connecting to their live chats.
  • Reading live chat messages so configured ! commands can be detected and answered.
  • Sending configured custom-command responses, the native !commands response, and configured timer messages.
  • Displaying connection, quota, and diagnostic status to the bot operator.
  • Refreshing OAuth access when needed so the bot can remain connected without repeated sign-in.

3. Storage and retention

  • OAuth access and refresh tokens are encrypted by the application before being stored in the application's MongoDB database.
  • The connected YouTube channel ID, channel display name, granted scopes, token expiration time, and update timestamps are stored while the YouTube connection remains configured.
  • YouTube live chat message text and chat-author details are processed in memory for command handling and are not persistently stored by the YouTube subsystem.
  • Recent chatter names and recently seen message IDs may be held temporarily in process memory for command features and duplicate protection. They are discarded when the relevant live-chat session ends or the process restarts.
  • Configured commands, timers, cooldowns, and related bot settings may be stored in the application database. These settings are created by the bot operator and are not Google account data.

4. Sharing and disclosure

SqwertArmyBot does not sell personal information or Google user data. Information is disclosed only as necessary to operate the service:

  • To Google/YouTube when making authorized YouTube API requests and sending live-chat messages.
  • To infrastructure providers used to run the application, including Render for application hosting and MongoDB for application data storage, to the extent technically necessary to provide the service.
  • When required by law or necessary to protect the security and integrity of the service.

YouTube live chat data accessed by this integration is not provided to advertisers, data brokers, or information resellers.

5. Security

SqwertArmyBot uses HTTPS for web and API traffic. Stored Google OAuth credentials are encrypted by the application before database storage. Access to administrative controls is restricted to the bot operator. No security measure is perfect, but the application is designed to minimize the amount of Google user data retained.

6. Your choices and deletion

The bot operator can disconnect YouTube OAuth from SqwertArmyBot's YouTube OAuth Management page. Disconnecting removes the stored YouTube OAuth credential record from the application database. Access can also be revoked from the connected Google account's third-party access/security settings.

For privacy or deletion questions, contact the SqwertArmyBot operator using the support contact shown on the Google OAuth consent screen or through the SqwertArmyBot YouTube channel.

7. Children's privacy

SqwertArmyBot is a livestream chat automation tool and is not designed to knowingly collect personal information from children. The application processes YouTube live-chat content supplied through YouTube's services only as described above.

8. Changes to this policy

This policy may be updated if SqwertArmyBot's features or data practices change. The "Last updated" date at the top of this page will be revised when material changes are made.

9. Google API Services

SqwertArmyBot's use and transfer of information received from Google APIs will adhere to the applicable Google API Services User Data Policy and YouTube API policies.
