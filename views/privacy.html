SqwertArmyBot Privacy Policy

Last updated: September 23, 2026

This Privacy Policy explains how SqwertArmyBot, a livestream chat automation bot used for GeneralQwert's Twitch and YouTube streams, accesses, uses, stores, and shares information. Features differ by platform: YouTube API data is used for the YouTube chat integration, while Twitch data may also be used by the AI-assisted features described below.

SqwertArmyBot does not sell personal information or use it for advertising. YouTube live chat data is not sent to Google Gemini or used for Twitch recaps, Tagged Questions, current-stream memory, Stream Lore, or Viewer Profiles. On Twitch, selected public chat, stream context, and Twitch events may be processed by Google Gemini to operate those AI-assisted features.

1. Google and YouTube data we access

When the SqwertArmyBot operator connects the bot through Google OAuth, the application may access the following information through the YouTube Data API:

  • The authorized bot channel's YouTube channel ID and display name.
  • OAuth access and refresh tokens, granted scopes, and token expiration information.
  • Public information about active GeneralQwert YouTube broadcasts, including video IDs, titles, and active live chat IDs.
  • Live chat information needed to operate commands: message text, message ID, publish time, the author's channel ID and display name, and whether the author is the chat owner, a moderator, or a sponsor/member.

2. How we use Google and YouTube data

SqwertArmyBot uses YouTube API data only to provide its YouTube livestream chat features, including:

  • Verifying that OAuth is connected to the intended SqwertArmyBot YouTube channel.
  • Finding active GeneralQwert YouTube livestreams and connecting to their live chats.
  • Reading live chat messages so configured ! commands can be detected and answered.
  • Sending configured custom-command responses, the native !commands response, and configured timer messages.
  • Displaying connection, quota, and diagnostic status to the bot operator.
  • Refreshing OAuth access when needed so the bot can remain connected without repeated sign-in.

YouTube live chat data is not used for the Twitch AI-assisted features described in Sections 3 and 4.

3. Twitch data and AI-assisted features

For GeneralQwert's Twitch channel, SqwertArmyBot may process public chat messages and related Twitch information such as usernames/display names, Twitch user IDs, message IDs and timestamps, reply or Shared Chat context, moderator/broadcaster status, stream metadata, and supported stream events.

When the relevant feature is enabled, selected Twitch chat, stream context, and event information may be sent to Google Gemini for AI processing. This supports features such as:

  • Hourly or on-demand stream recaps.
  • Tagged Questions and other configured AI-assisted answers.
  • Temporary current-stream memory used to answer questions about the same stream.
  • Stream Lore extraction and learning.
  • Viewer Profile learning, evidence checking, and profile-aware responses when that feature is enabled.

SqwertArmyBot does not operate or train its own general-purpose AI model. Gemini is used as an external processing service for the features above.

4. Viewer Profiles, learning, and opt-out / opt-in

Viewer Profiles are a Twitch-only feature. When automatic learning is enabled, eligible public Twitch chat may be analyzed to identify durable viewer-specific observations such as recurring habits, preferences, behaviors, or community context. A Viewer Profile may store the viewer's Twitch username/display name, Twitch user ID, known aliases, moderator-added notes, command-use counts, AI-generated observations and evidence metadata, and Viewer Profile preference/status information.

  • !optout stops Viewer Profile learning and profile use for that Twitch viewer immediately.
  • If a profile already exists, its profile content is retained for up to 30 days so the viewer can change their mind without losing it immediately.
  • After that 30-day retention period, stored profile content such as aliases, notes, learned observations, and command-use history is purged. A minimal identity and opt-out record is retained so automatic learning does not silently recreate a profile for someone who opted out.
  • !optin enables Viewer Profile participation again. If used within the 30-day retention period, the retained profile can be reactivated; after profile content has been purged, the profile starts fresh.

The !optout / !optin choice applies specifically to Viewer Profile learning and use. Public Twitch chat may still be processed by other enabled stream features, such as recaps or current-stream memory, because those features operate independently of Viewer Profiles.

5. Storage and retention

  • Google OAuth access and refresh tokens are encrypted by the application before being stored in the application's MongoDB database.
  • The connected YouTube channel ID, channel display name, granted scopes, token expiration time, and update timestamps are stored while the YouTube connection remains configured.
  • YouTube live chat message text and chat-author details are processed in memory for command handling and are not persistently stored by the YouTube subsystem. Recent chatter names and recently seen message IDs may be held temporarily in process memory for command features and duplicate protection.
  • Twitch chat and event snapshots may be stored temporarily in MongoDB during an active stream for recap recovery and delayed learning. Pending learning snapshots are removed after the relevant learning work completes.
  • Temporary current-stream memory and internal recap history are cleared when the stream session ends. A short-lived stream-session tombstone may remain for up to 7 days without the cleared chat or memory content so late writes from an old process cannot recreate the session.
  • Viewer Profiles may remain stored while a viewer participates in that feature. The Viewer Profile opt-out retention behavior is described in Section 4.
  • Stream Lore and other operator-approved channel-level learning may remain stored until the operator edits or deletes it.
  • Configured commands, timers, cooldowns, AI settings, and related bot settings may be stored in the application database.

6. Sharing and disclosure

SqwertArmyBot does not sell personal information or platform user data. Information is disclosed only as necessary to operate the service:

  • To Twitch when connecting to Twitch services and sending bot messages.
  • To Google/YouTube when making authorized YouTube API requests and sending YouTube live-chat messages.
  • To Google Gemini when an enabled Twitch AI-assisted feature needs selected Twitch chat, stream context, or event information for processing.
  • To infrastructure providers used to run the application, including Render for application hosting and MongoDB for application data storage, to the extent technically necessary to provide the service.
  • When required by law or necessary to protect the security and integrity of the service.

YouTube live chat data accessed by the YouTube integration is not provided to Gemini, advertisers, data brokers, or information resellers.

7. Security

SqwertArmyBot uses HTTPS for web and API traffic. Stored Google OAuth credentials are encrypted by the application before database storage. Access to administrative controls is restricted to the bot operator. No security measure is perfect, but the application is designed to limit retained data to what is needed for enabled features and operational recovery.

8. Your choices and deletion

Twitch viewers can use !optout and !optin in GeneralQwert's Twitch chat to control Viewer Profile learning and use as described in Section 4. Privacy or deletion questions can also be directed to the SqwertArmyBot operator.

The bot operator can disconnect YouTube OAuth from SqwertArmyBot's YouTube OAuth Management page. Disconnecting removes the stored YouTube OAuth credential record from the application database. Access can also be revoked from the connected Google account's third-party access/security settings.

For privacy or deletion questions, contact the SqwertArmyBot operator using the support contact shown on the Google OAuth consent screen or through the SqwertArmyBot YouTube channel.

9. Children's privacy

SqwertArmyBot is a livestream chat automation tool and is not designed to knowingly collect personal information from children. It processes public livestream chat and related platform information only for the features described in this policy.

10. Changes to this policy

This policy may be updated if SqwertArmyBot's features or data practices change. The "Last updated" date at the top of this page will be revised when material changes are made.

11. Google API Services

SqwertArmyBot's use and transfer of information received from Google APIs will adhere to the applicable Google API Services User Data Policy and YouTube API policies.
