Available Variables

$(user) or $user
Viewer who triggered the command. Example: Hello $(user)! → Hello SomeViewer!
$(touser) or $touser
First argument after the trigger, with a leading @ removed; falls back to the triggering viewer. Example: !bonk @Qwert + Bonked $(touser)! → Bonked Qwert!
$(query) or $query
Everything after the trigger. Example: !say hello there + You said: $(query) → You said: hello there
$(count) or $count
Persistent counter after a successful trigger increments it. Example: Hydration #$(count) → Hydration #42
$(counter) or $counter
The same persistent counter with an ordinal suffix. Examples: $(counter) → 1st, 2nd, 3rd, 11th, 22nd.
$(random MIN MAX [DEC])
Random number from MIN through MAX, inclusive. Without DEC it returns a whole integer. Optional DEC sets decimal places from 0–5. Example: $(random 1 10 5) → 3.14159.
$(randomuser)
Random current Twitch chatter, excluding SqwertArmyBot and known utility bots. Example: $(randomuser) has been selected!
$(followage) or $followage
How long $(touser) has followed Qwert, formatted compactly for chat (for example 2 years, 3 months, 18 days, or 42 seconds). With no command argument, this checks the viewer who triggered the command. Example: Following for $(followage).
$(followdate) or $followdate
UTC calendar date when $(touser) followed Qwert. Example: Following since $(followdate).
$(game) or $game
Twitch category currently being played, or the last category played, by $(touser). With no command argument, this checks the viewer who triggered the command. Example: They were last playing $(game).
Each response supports up to 500 characters.

Edit Rotating Pinned Banners

Banners
Banners rotate from top to bottom. Disable an individual banner to skip it without deleting its text.
Each banner can optionally use a reusable Advanced Filter from General Settings. Ineligible banners are skipped automatically. With exactly one eligible enabled banner, duration settings are ignored and that banner stays pinned indefinitely. With 2+ eligible enabled banners, a banner-specific duration is optional and can only extend that banner; blank values, or values at/below the global duration, use the global duration. A recap may temporarily replace the active banner; recap display time is deducted from that banner's remaining slot. Manual or other pins are never automatically replaced by the rotation.

EventSub $(game) is retired and no longer returns the stream category.
