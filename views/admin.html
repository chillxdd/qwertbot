Available Variables

$(user) or $user
Viewer who triggered the command. Example: Hello $(user)! → Hello SomeViewer!
$(touser) or $touser
First argument after the trigger, with a leading @ removed; falls back to the triggering viewer. Example: !bonk @Qwert + Bonked $(touser)! → Bonked Qwert!
$(query) or $query
Everything after the trigger. Example: !say hello there + You said: $(query) → You said: hello there
$(count) or $count
Persistent counter after a successful trigger increments it. Example: Hydration #$(count) → Hydration #42
$(counter) or $counter
The same persistent counter with an ordinal suffix. Examples: $(counter) → 1st, 2nd, 3rd, 11th, 22nd.
$(random MIN MAX [DEC])
Random number from MIN through MAX, inclusive. Without DEC it returns a whole integer. Optional DEC sets decimal places from 0–5. Example: $(random 1 10 5) → 3.14159.
$(randomuser)
Random current Twitch chatter, excluding SqwertArmyBot and known utility bots. Example: $(randomuser) has been selected!
$(followage) or $followage
How long $(touser) has followed Qwert, formatted compactly for chat (for example 2 years, 3 months, 18 days, or 42 seconds). With no command argument, this checks the viewer who triggered the command. Example: Following for $(followage).
$(followdate) or $followdate
UTC calendar date when $(touser) followed Qwert. Example: Following since $(followdate).
$(game) or $game
Twitch category currently being played, or the last category played, by $(touser). With no command argument, this checks the viewer who triggered the command. Example: They were last playing $(game).
Each response supports up to 500 characters.

Shows the saved last notable Pokémon run clip. Uses a 30-second global cooldown.
Built-in
!clipModerator
Creates a live Twitch clip. Blank titles get a fast neutral gaming title from Gemini, with deterministic/Twitch fallback. Uses a 60-second global cooldown.
Built-in
!cliplastModerator
Creates a Twitch clip and saves it as !last. Blank titles get a fast negative run-loss title from Gemini. Shares a 60-second cooldown with !setlast and only works while live in an approved official Pokémon category.
Built-in
!setlastModerator
Validates a Qwert Twitch clip URL and saves it as !last. Shares a 60-second cooldown with !cliplast and only works while live in an approved official Pokémon category.
Built-in
!startrecapModerator
Resumes automatic hourly recaps after they have been paused.
Built-in
!stoprecapModerator
Pauses automatic hourly recaps while preserving the current recap window.
Built-in
!repinModerator
Enables Persistent Stream Pin and restores the configured pin immediately.
Built-in
!unpinModerator
Unpins the current message and disables Persistent Stream Pin.
Built-in
!optoutEveryone
Opts the viewer out of Viewer Profiles immediately. Learning and AI use stop at once; the existing profile is retained for 30 days in case they opt back in, then its stored profile content is deleted.
Built-in
!optinEveryone
Opts the viewer back into Viewer Profiles. If they return within 30 days, their retained profile is reactivated; after that, a new profile starts fresh.
